# Schwung WaveWarp

Sound generator module for [Schwung](https://github.com/charlesvestal/schwung) on Ableton Move.

Experimental spectral warping wavetable synthesizer derived from the GPLv3 Vital source code. Exposes a reduced parameter set focused on oscillator shape, voice envelope, mix, macros, and FX. Ships with bundled CC0 presets.

**Author:** Andre Louis

## Build

Requires a Vital source checkout:

```bash
VITAL_ROOT=/path/to/vital ./scripts/build.sh
```

## Install

```bash
./scripts/install.sh
```

## Bundled Presets

Presets from [Abstraction Mage's Vital-Presets](https://github.com/abstractionmage/Vital-Presets), distributed under CC0 1.0. See `docs/PRESET_SOURCES.md` for attribution.
